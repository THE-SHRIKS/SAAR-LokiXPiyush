# ADR 0004: Local Model Runtime and Sidecar Specification

## Status
Accepted

## Context
In accordance with `Docs/AGENTS.md`, `Docs/RULES.md`, `Docs/PRD.md`, `Docs/PLAN.md`, and `Docs/TASKS.md` (tasks P0-04 and P0-05):
1. OpenDeck operates strictly local-first with zero external cloud dependencies at runtime, zero telemetry, and zero data leakage.
2. The Debian host environment runs on an Intel Core i3-7020U (2 physical cores / 4 threads @ 2.30 GHz) with AVX2 instruction support and 11 GiB RAM, without discrete GPU / CUDA acceleration. The release target is native 64-bit Windows 10/11.
3. Financial extraction requires deterministic, constrained structured JSON output that conforms strictly to schema validation and guarantees exact minor-unit integer arithmetic (no binary floating-point representation for currency).

## Decisions

### 1. Primary Language Model: Qwen2.5-3B-Instruct (Q3_K_M GGUF)
- **Model Identity:** Qwen2.5-3B-Instruct quantized with k-quant `Q3_K_M`.
- **License:** Apache License 2.0 (permissive, commercial and offline use authorized).
- **Integrity Pinned Hash:**
  - File: `models/weights/Qwen2.5-3B-Instruct-Q3_K_M.gguf`
  - Size: 1,590,475,936 bytes (~1.48 GiB)
  - SHA-256: `8eff4e0eb51a8148abdaa9849f14f187e5ac6cd7d795610caf996a287277c59d`
- **Memory & Resource Budget:**
  - With a 2048-token context window (`-c 2048`), peak inference RSS is ~1.8 GiB.
  - Leaves >8.5 GiB RAM headroom on an 11 GiB system, allowing simultaneous operation with the Tauri desktop shell (<150 MB) and RapidOCR worker (<200 MB).
- **CPU Fallback & Threading:**
  - Strictly constrained to 2 execution threads (`-t 2`) to match the 2 physical CPU cores, avoiding scheduler thrashing and thermal throttling.

### 2. Runtime Engine: llama.cpp Sidecar
- **Engine:** llama.cpp native binary build with AVX2 and FMA acceleration.
- **License:** MIT License.
- **Constrained Decoding:**
  - Employs grammar-based sampling (`--json-schema`) backed by GBNF inside llama.cpp.
  - Every sampled token is masked against the grammar DFA, guaranteeing that model output is 100% syntactically valid JSON matching the schema.
  - Greedy sampling (`--temp 0.0`) ensures deterministic reproducibility for identical document contexts.
- **Numeric Schema Discipline:**
  - All currency values are defined as integer minor units (e.g. `total_cents`, `tax_cents`, `amount_cents`). Floating point types are prohibited in the schema.

### 3. Windows Release & Packaging Strategy (P0-05)
- **Sidecar Architecture:**
  - The desktop Tauri 2 application supervises the `llama-cli` / worker executable as a local child process.
  - Communications take place over standard I/O (JSON line streams) or local loopback IPC, isolated from any network interfaces.
  - Zero external Python or Rust runtime required on the end-user machine.
- **Windows Toolchain:**
  - llama.cpp builds cleanly under MSVC 2022 on Windows x64 with AVX2 (`-DGGML_AVX2=ON`).
  - RapidOCR models (`ch_PP-OCRv4_det_infer.onnx`, `ch_ppocr_mobile_v2.0_cls_infer.onnx`, `en_PP-OCRv4_rec_infer.onnx`) run via native Windows ONNXRuntime C++ / C# / PyInstaller-frozen binary.
  - Bundled sidecars and model weights are packaged into the WiX MSI / NSIS offline installer generated by Tauri 2.
